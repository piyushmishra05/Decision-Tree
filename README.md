# Decision Tree Classification for Data Analysis

This repository documents my structured learning and hands-on practice of **Decision Tree algorithms**, focusing on both **binary and multi-class classification problems**. The notebooks cover theoretical concepts as well as practical implementation using **Python (Jupyter Notebooks)**.

---

## 📌 Project Overview

Decision Trees are intuitive and powerful machine learning models widely used in data analysis and classification tasks.  
This project explores:
- How decision trees split data using impurity measures
- How tree-based models make predictions
- Differences between binary and multi-class classification using decision trees

---

## 📊 Topics Covered

### 🔹 Decision Tree Fundamentals
- Structure of a decision tree (nodes, branches, leaves)
- Binary vs multi-class classification
- Decision boundaries and rule-based learning

### 🔹 Splitting Criteria
- Gini Index
- Entropy
- Information Gain
- Comparison of splitting methods

### 🔹 Model Building & Training
- Implementing Decision Tree classifiers using Python
- Training models on datasets
- Visualizing and interpreting decision rules

### 🔹 Model Evaluation
- Accuracy score
- Confusion matrix
- Classification performance comparison
- Understanding overfitting in decision trees
